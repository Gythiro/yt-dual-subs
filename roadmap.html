Subtitles stop repeating themselves

同语言字幕不再重复翻译

On a video whose subtitles are already in your target language, the second line used to repeat the first. It now shows a single line instead.

字幕本来就是目标语言的视频，第二行会把第一行原样重复一遍。现在直接只显示一行。

Use your own API key

自带 Key 翻译

Bring a key from DeepSeek, Gemini, DeepL and a dozen others. Each sentence is understood as a whole and then split back across the subtitles, so the translation line stops lagging a sentence behind — and a whole video can be exported as SRT through your own engine.

用你自己的 Key（DeepSeek、Gemini、DeepL 等十余家）。译文会整句理解之后再按字幕切回来，不再一整句杵在那儿不动；导出整片 SRT 也能走你自己的引擎。

教程页与新手入门

A per-provider walkthrough for getting a key, and a short first-run page inside the extension for everything you can do without one.

每家服务商怎么申请 Key 的分步说明，加上扩展内一页很短的入门——讲不配置也能用的那部分。

Study mode

学习模式

Blur the translation until you hover it, and pause the video while you read — so you get a chance to guess first. It will be a switch you can turn off: letting the mouse rest on the subtitles takes that small area away from the player's own clicks.

译文先模糊，鼠标悬上去才显示，同时自动暂停视频让你读完——这样才有"先自己猜一下"的机会。它会做成一个可以关掉的开关：让鼠标能停在字幕上，就会占掉那一小块区域的播放器点击。

Usage panel

用量面板

For own-key users: how many tokens this video actually cost. Token counts come from the provider's own response, so they are exact. A money estimate is optional, off unless you enter a price, and always labelled an estimate — a wrong number is worse than no number.

给用自带 Key 的人：这个视频到底花了多少 token。token 数来自服务商自己的返回，是准的。花费估算是可选的，不填单价就只显示 token 数，而且一律标注"估算"——显示一个错的金额比不显示更糟。

Low-traffic mode

省流模式

Translate less far ahead. Fewer requests and less spend, at the cost of the occasional short wait when you skip around.

少往前预读几句。请求更少、花费更低，代价是跳着看的时候偶尔要等一下。

Our own plan 开发者计划

⏸Not planned暂不计划

Asked for before, with the reason it is not happening.

有人问过，这里写清楚为什么不做。

Local models (Ollama, localhost)

本地模型（Ollama / localhost）

Reaching localhost needs a permission that browser stores treat as high risk, and it would apply to every user to serve a few. Any local server with an OpenAI-compatible HTTPS address already works through "custom endpoint".

访问 localhost 需要一项被应用商店视为高风险的权限，而且为了少数人要向所有人申请。本地服务只要能给出 OpenAI 兼容的 https 地址，走「自定义接口」就已经可以用。

A video tutorial

视频教程

It goes stale the moment YouTube moves a button, and it would need re-recording per language. The written guide is easier to keep correct, which is the part that matters.

YouTube 挪一个按钮它就过期了，而且每种语言都要重录一遍。文字教程更容易保持正确——正确才是重点。

We pay for the API for you

我们代付 API / 内置中转

That needs a server, and every subtitle would have to pass through it. This extension has no server and collects nothing; keeping it that way is worth more than the convenience.

那需要一台服务器，而且你的每一条字幕都要经过我们的手。这个扩展没有服务器、不做任何统计；守住这一点比那点方便更值。

Shorter sentence grouping

更短的断句

Tried it, measured it side by side, and the shorter grouping translated worse. Keeping a known-worse setting as an option would just be a trap.

试过了，也做了 A/B 对比，更短的断句翻得更差。把一个已知更差的设置留成选项，只会变成一个坑。

Missing something? Just say so. Every item above marked as coming from a user was somebody's message — that is genuinely how things get onto this list.

有想要但没在上面的？说一声就行。上面标着来源的每一条，都是别人发过来的一句话——功能真的就是这么进这个列表的。
