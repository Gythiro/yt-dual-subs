Spoken lines fit the picture

念出来的话跟画面贴得更准

A line that runs long slows the picture a little and borrows the gap after it instead of losing its last words, and a switch keeps slowing until every line finishes. Listened to on real videos at 1× and 2× before it shipped.

句子长了会稍微放慢画面、借用后面的空隙，而不是丢掉最后几个字；还有一个开关能一直放慢到句句读完。发出之前在真视频上以 1 倍和 2 倍速听过。

更多界面语言

Fonts from your own computer

用你自己电脑上的字体

The popup offers the fonts really installed on this computer, judged per subtitle line; a settings page previews any of them at subtitle size and imports a font file of your own. The fixed list of fifteen names is gone.

弹窗里列的是这台电脑上真装了的字体，按字幕行判断能不能显示；设置页可以按字幕大小预览任何一个，还能导入你自己的字体文件。写死的十五个名字没有了。

Read the translation out loud

把译文念出来

Each line is spoken as it appears, in your translation language, with the video's own audio ducking underneath rather than being replaced. It starts on your browser's own voices — no key, nothing leaving the machine with the voices installed on it — and five services can be plugged in for better ones.

每句字幕出现时就用你的译文语言念出来，视频原声只是压低，不会被替换。默认用浏览器自带的音色——不用 Key，用本机装好的音色时什么都不离开这台机器；想要更好的声音，可以接五家服务。

Summarize a video into chapters

把视频总结成章节

One line of TL;DR plus timestamped chapters you can click to jump, written in your translation language. It runs on a service of yours, and nothing is sent until you press the button that says how much it will send and where.

一句摘要加上带时间戳的章节，点一下就跳过去，用你的译文语言写。它走你自己的服务；在你按下那颗写明「发多少、发给谁」的按钮之前，什么都不会发出去。

Local models (Ollama, LM Studio)

本地模型（Ollama / LM Studio）

This sat under "not doing" on the strength of a guess: that reaching localhost needed a permission the stores treat as high risk, asked of everyone to serve a few. It does not. Pick Ollama (local) from the list, or type an address into the custom endpoint; Chrome asks for that one host when you press Save and test, so anyone who never goes there is never asked for anything. Translation and summaries both run on it, and the guide walks through the one setting everybody misses.

这条原本挂在「暂时不做」，理由是个猜测：以为访问 localhost 要一项被商店视为高风险的权限，而且要向所有人申请。其实不用——在清单里选「Ollama（本机）」，或在自定义接口填一个地址；按「保存并测通」时 Chrome 才为那一个域名申请；没去过那里的人，不会被问任何事。翻译和总结都能走它，教程里一步步写了，包括所有人都会漏掉的那个设置。

Being built正在做

Read-aloud's default. A long line already slows the picture a little, but not as far as it takes, so a line is still cut now and then; the switch that keeps slowing until every line finishes is off by default. Whether that trade is right — or the switch should be the default — is being decided by ear on real videos.

朗读的默认值。句子长了现在已经会稍微放慢画面，但不放慢到读完为止，所以偶尔仍会切掉一句；「尽量每句读完」那个开关默认是关的。这个取舍对不对——还是该把开关设成默认——靠在真视频上用耳朵定。

Study mode

学习模式

Blur the translation until you hover it, and pause the video while you read — so you get a chance to guess first. It will be a switch you can turn off: letting the mouse rest on the subtitles takes that small area away from the player's own clicks.

译文先模糊，鼠标悬上去才显示，同时自动暂停视频让你读完——这样才有「先自己猜一下」的机会。它会做成一个可以关掉的开关：让鼠标能停在字幕上，就会占掉那一小块区域的播放器点击。

Usage panel

用量面板

For own-key users: how many tokens this video actually cost. Token counts are the provider's own, not an estimate of ours. A money estimate is optional, off unless you enter a price, and always labelled an estimate — a wrong number is worse than no number.

给用自带 Key 的人：这个视频到底花了多少 token。token 数是服务商自己返回的，不是我们估的。花费估算是可选的，不填单价就只显示 token 数，而且一律标注「估算」——显示一个错的金额比不显示更糟。

Firefox, and other extension stores

Firefox，以及别的扩展商店

A contributor showed Firefox needs almost no code changes, and the bring-your-own-key path works there. What is missing is not code: a Firefox add-on has to be signed through addons.mozilla.org before it will install at all, and none of the checks here run under Firefox. Edge and other Chromium browsers already work today — they install from the Chrome Web Store.

有贡献者证明了 Firefox 几乎不用改代码就能支持，自带 Key 在那边也实测通过。缺的不是代码：Firefox 扩展必须经 addons.mozilla.org 签名才装得上，而这里的检查没有一道跑在 Firefox 上。Edge 和其他 Chromium 浏览器现在就能用——从 Chrome 应用商店安装。

A video tutorial

视频教程

It goes stale the moment YouTube moves a button, and it would need re-recording per language. The written guide is easier to keep correct, which is the part that matters.

YouTube 挪一个按钮它就过期了，而且每种语言都要重录一遍。文字教程更容易保持正确——正确才是重点。

We pay for the API, or proxy it for you

我们代付 API / 内置中转

That needs a server, and every subtitle would have to pass through it. This extension has no server and collects nothing; keeping it that way is worth more than the convenience.

那需要一台服务器，而且你的每一条字幕都要经过我们的手。这个扩展没有服务器、不做任何统计；守住这一点比那点方便更值。

Shorter sentence grouping

更短的断句

Tried it, measured it side by side, and the shorter grouping translated worse. Keeping a known-worse setting as an option would just be a trap.

试过了，也做了 A/B 对比，更短的断句翻得更差。把一个已知更差的设置留成选项，只会变成一个坑。
