v3.7.0 2026-08-22 You are here当前版本

The three big ones this time: the translation read out loud, a video summarized into chapters, and the models and fonts on your own computer. The 22 items below run new → improved → changed → fixed.这一版的三件大事：把译文念出来、把视频总结成章节、用你自己电脑上的模型和字体。下面 22 条按新增 → 改进 → 变更 → 修复排。

  • NEW新增

    It can read the translation out loud. Each line is spoken as it appears; the video's own audio ducks underneath, and a line that runs long slows the picture a touch and borrows the gap after it, so most lines get to finish; a switch in the settings (Try to finish every line) keeps slowing so more of them do. Your browser's own voices need no key at all — turn the switch on in the popup and it works. Five cloud providers are there for better ones, including Chinese regional voices and, on ElevenLabs, voices you cloned yourself. Press Preview to hear a voice speak your language before choosing it.

    可以把译文念出来了。每句字幕出现时就朗读它的译文，视频原声自动压低；句子长到读不完时，视频会稍微放慢、借用后面的空隙，大多数句子能读完；要句句都读完，设置里有「尽量每句读完」的开关。用浏览器自带音色不需要 Key——在弹窗里打开开关就能用。想要更好的声音，还有五家云服务商，含中文方言音色，ElevenLabs 上还能用你自己克隆的声音。选之前点「试听」，会用你的译文语言念一句给你听。

  • NEW新增

    Subtitles can be selected and copied — off by default, since selecting would get in the way of click-to-pause; turn it on in the small menu behind the arrow on the player's subtitle button (the item is called Select text; the popup's Layout card has the same switch). That menu also reaches the switches you use while watching, without opening anything.

    字幕可以选中复制了——默认关着，因为选中会挡住点画面暂停；在播放器字幕按钮上的小箭头菜单里打开（那一项叫「选中复制」，弹窗「布局」卡里也有同一个开关）。那个小菜单也放着看视频时要动的几个开关，不用打开任何页面就能够到。

  • NEW新增

    The interface speaks 44 languages. It follows your browser, and Settings → About → Interface language lets you set it by hand — separately from the language your subtitles are translated into.

    界面支持 44 种语言。自动跟随浏览器，也可以在设置页 →「关于」→「界面语言」里手动指定——它和「字幕翻译成什么语言」是两件事。

  • NEW新增

    Six looks to choose from. Settings → About → Interface appearance offers Default, Neon Terminal, Ember, Mocha, Ink and Dusk. It repaints the popup and the settings page only — the subtitles on the video keep the font and colours you set in Line style. Default is still the default.

    六套外观可选。设置页 →「关于」→「界面外观」里有默认、霓虹终端、余烬、摩卡、墨、暮色。只影响这个扩展自己的弹窗和设置页——视频上那两行字幕的字体和颜色，照旧在「行样式」里调。默认那一套仍然是默认。

  • NEW新增

    A whole video, summarized into chapters. One line of TL;DR plus timestamped chapters, written in your translation language; click a timestamp to jump there. It runs on a service of yours — the free engines translate but do not summarize — and nothing is sent until you press the button that says how much it will send and where.

    一支视频，总结成带时间戳的章节。一句摘要加上分章，用你的译文语言写；点时间戳就跳过去。它走你自己的服务——免费引擎只翻译，不总结——而且在你按下那颗写明「发多少、发给谁」的按钮之前，什么都不会发出去。

  • NEW新增

    A model on your own computer can do both. Pick Ollama (local) from the provider list — nothing to type — or point the custom endpoint at LM Studio, and translation and summaries run locally: nothing per video, and the subtitles never leave the machine. The guide walks through it, including the one setting everybody misses.

    你自己电脑上的模型也能干这两件事。在服务商列表里选「Ollama（本机）」——什么都不用填——或者把自定义接口指向 LM Studio，翻译和总结就都在本地跑：看多少视频都不花钱，字幕也不会离开这台机器。教程里一步步写了，包括所有人都会漏掉的那个设置。

  • NEW新增

    The translation model changes from the popup. The line that names the model is now the control for it: what you used lately, and what your key already fetched, are one click away — the whole list is one more. Lines already on screen keep the translation they were given; the new model starts with the next one. The voice menu works the same way, keeping the voice in use and the ones you used lately, with the full catalogue on the settings page.

    换翻译模型不用离开视频了。点弹窗里写着模型名的那一行就能换：最近用过的、你的 Key 拉过的都在里面，想看全部再点一下就到设置页。已经出来的句子保持原来的译文，新模型从下一句开始。音色单也是同一个做法——留你在用的和最近用过的，完整清单在设置页。

  • NEW新增

    Fonts from your own computer. The font list used to be fifteen fixed names, some of them installed nowhere near you; choosing one quietly gave you something else. The popup now offers the fonts really installed on this computer, judged per line: a font that cannot draw Japanese is left off the Japanese line — one closing row says how many were left out, and the font in use stays, marked. Settings → Subtitle fonts shows every font on the computer, previews any of them at subtitle size in the language you pick, keeps the ones you want in the popup, and imports a font file of your own — copied into the browser, so the original can move afterwards. This needs the browser's font-list permission (fontSettings); Chrome shows no warning for it, so the privacy policy spells it out: read-only, used on your computer.

    字体来自你自己的电脑。以前字体下拉是写死的十五个名字，有几个在你机器上根本没装，选了会悄悄换成别的。弹窗里现在列的是这台电脑上真装了的字体，而且按行判断：显示不了日文的字体，在日文那一行里不再列出——末尾一行写着另有几个显示不了，正在用的那个留着并标明。设置 →「字幕字体」列出电脑上的全部字体，可以按你选的语言、按字幕大小预览任何一个，把想在弹窗里看到的留下，还能导入你自己的字体文件——拷一份存进浏览器，之后原文件挪走也不影响。这需要浏览器的字体清单权限（fontSettings）；Chrome 不会为它弹提示，所以隐私政策里专门写了一段：只读，只在你电脑上用。

  • NEW新增

    When something is wrong, one button explains it. Settings → About → Something not working now carries a three-step checklist and a Copy diagnostic info button — and the popup shows the same button whenever something is wrong — so a bug report can start with facts instead of guesses.

    出问题时，有一颗按钮替你说清楚。设置 →「关于」→「遇到问题」里加了三步自检和「复制诊断信息」，弹窗出问题时也会露出同一颗按钮；报问题时可以直接贴事实，不用来回猜。

  • NEW新增

    Three keyboard shortcuts, unbound until you bind them. Subtitles on/off, read-aloud on/off, and show or hide the translation line — the last one for reading the original first and checking yourself afterwards. Each can be given a key in Chrome's shortcut settings (Settings → About → Set shortcuts). Nothing is bound out of the box, so nothing changes until you choose to. Suggested by @LemuelCushing.

    三条键盘快捷键，不绑就不生效。开关字幕、开关朗读，以及开关译文行——最后这条是给想先看原文、再对答案的人用的。每条都可以在 Chrome 的快捷键设置里绑一个键（设置 →「关于」→「设置快捷键」）。默认一个都没绑，所以不绑就什么都不变。由 @LemuelCushing 提议。

  • IMPROVED改进

    A refusal now says which thing to go and fix. "The key was rejected" used to cover both a key that is wrong and a key that is fine on an account that is not allowed to make the call — an unpaid balance, an identity check, a model not switched on. Those are different sentences now, an empty balance is no longer described as something to retry, and whatever the provider itself said is printed underneath.

    被拒绝时，会说清该去修哪一头。以前「Key 被拒绝」既指 Key 写错，也指 Key 没问题、只是这个账号不被允许这样调用——余额不足、实名没做、模型没开通。现在这两件事是两句话；余额用完不再被说成「稍后再试」；服务商自己说的那句原话也会显示在下面。

  • IMPROVED改进

    A saved key says so, instead of leaving an empty box. It now reads "saved ····1234" with Replace and Delete beside it. The old row showed an empty field and a link called "Clear", which two readers in a row took to mean "empty this box" rather than "delete the key".

    存好的 Key 会明说，而不是留一个空框。那一行现在写着「已保存 ····1234」，旁边是「更换」和「删除」。以前是一个空输入框加一个叫「清除」的链接，连着两位读者都把它理解成「清空这个框」而不是「删掉这把 Key」。

  • IMPROVED改进

    The setup form now runs in the order you have to work in. The API key comes before the model, because the model list is fetched with the key; with no key the model row says so by being unavailable rather than by refusing a click; and pressing "Save and test" with no model chosen says so at once instead of after a round trip that had already switched the extension over.

    配置那一面改成了按实际操作顺序排。API Key 排在模型之前——模型清单本来就是用 Key 拉的；没填 Key 时模型那一格直接不可用，而不是点了才拒绝；没选模型就按「保存并测通」，当场就说，而不是走完一轮网络请求、而那时扩展已经切过去了。

  • IMPROVED改进

    Reset asks first. "Reset all settings" now opens a small panel that says exactly what goes — every setting, the API keys on this computer, and the model and voice remembered for each provider; that the first-run hints come back; and that the domains you already allowed stay allowed — before it does anything.

    重置前会先问一句。「重置全部设置」现在会先弹一个小面板，说清会清掉什么——所有设置、这台电脑上的 API Key、各家记住的模型和音色；首次使用的提示会重新出现；已经授权过的域名保持授权——确认了才动手。

  • IMPROVED改进

    A retired model no longer fails silently. Once a key has tested successfully, the model list is fetched from the provider once, quietly; if the model you are using is no longer on it, the settings page says so and asks you to pick another, instead of every translation failing.

    模型下架不再悄悄失败。Key 测通之后，悄悄向服务商拉一次模型清单；你正在用的模型不在清单里了，设置页会说出来、请你另选一个，而不是每一句翻译都失败。

  • IMPROVED改进

    An export through your own key waits out a rate limit instead of running into it. When that provider has just rate-limited you, the download shows a countdown and starts the moment the gate opens; Stop still stops it, and a download you replaced with another no longer wakes up and spends your quota.

    用自带 Key 导出时会等限流过去，不再一头撞上去。那家服务商刚限流，下载就显示倒计时，门一开就开始；「停止」照样能停，被你换掉的那次下载也不会再醒过来花你的额度。

  • CHANGED变更

    Needs Chromium 111 or newer (it was 102). Chrome, Edge and the other Chromium browsers from March 2023 on; on an older browser this update does not arrive, and 3.6.0 keeps working as it was.

    最低需要 Chromium 111（原来是 102）。2023 年 3 月以后的 Chrome、Edge 和其他 Chromium 浏览器都够；更老的浏览器收不到这次更新，3.6.0 会照旧运行。

  • FIXED修复

    Japanese and Traditional Chinese subtitles were drawn in Simplified Chinese shapes. 直 角 骨 社 are written differently in Japanese, Taiwan and mainland typography; the overlay had never told the browser which language a line was in, so the browser guessed. Each line now carries its language and the browser picks that language's glyphs, whichever font you chose. If Japanese subtitles look a little different after this update, that is why.

    日语和繁体字幕一直被用简体中文的字形画出来。直、角、骨、社这些字在日本、台湾和大陆的写法本来就不一样；叠加层从来没告诉浏览器这一行是什么语言，浏览器只好猜。现在每一行都带着自己的语言，浏览器会按那种语言选字形，不管你选的是哪个字体。更新后日语字幕看着有点不一样，原因就在这里。

  • FIXED修复

    Read-aloud refused seventeen languages for no reason. Google's voice list had grown and ours had not, so Swedish, Finnish, Danish, Norwegian, Czech, Greek, Hungarian, Romanian, Hebrew and eight more were told the provider could not speak them. It could.

    朗读无理由拒绝了十七种语言。Google 的音色支持范围扩大了而我们的表没跟上，导致瑞典语、芬兰语、丹麦语、挪威语、捷克语、希腊语、匈牙利语、罗马尼亚语、希伯来语和另外八种语言被告知「这家不支持你的语言」。其实是支持的。

  • FIXED修复

    A key from a provider's international site was refused as if it were wrong. SiliconFlow, Alibaba's 百炼, Kimi and GLM each run a mainland-China platform and an international one, on separate accounts whose keys are not interchangeable — and the address was hard-coded to one of them. Anyone holding the other kind of key was told the key had been rejected. The provider panel now has a Site row for those four and for the two read-aloud providers with the same split. Reported by @LemuelCushing.

    在服务商海外站申请的 Key 被当成错的拒掉了。硅基流动、阿里云百炼、Kimi、智谱 GLM 都是国内站和海外站两套独立平台，账号与 Key 不通用，而我们把地址写死成了其中一个。持另一边 Key 的人会被告知「Key 被拒绝」。现在这四家、以及同样有两套平台的两家朗读服务商，面板上都多了一行「站点」。由 @LemuelCushing 报告。

  • FIXED修复

    A video already set to YouTube's own auto-translation showed no subtitles until you changed the track by hand, with the retry notice up the whole time. The original track is now read straight off that selection, and later token rotations keep working — a language change or an SRT export mid-video no longer fetches with a stale token.

    已经选了 YouTube 自动翻译轨的视频不出字幕，得手动换一次轨才恢复，重试提示也一直不消。现在直接从那条轨读原文轨，后面的令牌轮换也跟得上——视频中途换语言或导出 SRT 不再用过期令牌。

  • FIXED修复

    The translation line no longer ends with the first word of the next sentence. YouTube translates scrolling captions fragment by fragment and cuts wherever a fragment ends; with your own key the translation line now shows whole sentences, while the original line keeps scrolling with what is being said.

    译文行不再拖着下一句的第一个字。YouTube 对滚动字幕逐段翻译、段尾就切；用自带 Key 时，译文行现在整句显示，原文行照旧跟着说话逐段滚动。

  • FIXED修复

    A caption feed that dies mid-video is retried for as long as the video plays. Three quick retries used to be the whole budget, and a YouTube rate-limit window outlives all three; the retries now space out — 40 seconds, 80, up to five minutes apart — instead of giving up with the last line frozen on screen.

    字幕流在视频中途断掉，现在会一直重试到视频结束。以前只有三次快速重试，YouTube 的限流窗口比它们三个加起来都长；现在重试间隔逐步拉长——40 秒、80 秒，最长 5 分钟一次——不再放弃、不再把最后一行冻在屏幕上。

v3.6.0 2026-07-27 You are here当前版本
  • NEW新增

    Translate with your own API key. Bring a key from DeepSeek, Gemini, DeepL, Alibaba Bailian — twelve providers in all. Each sentence is understood as a whole and then split back across the subtitles, so the translation line turns over with the original instead of standing still. The key is stored on this computer only and is sent to nobody but the provider you picked.

    可以用你自己的 API Key 翻译了。支持 DeepSeek、Gemini、DeepL、阿里百炼，共 12 家。译文会整句理解之后再按字幕切回来，不再一整句杵在那儿不动。Key 只存在这台电脑上，除了你选的那家服务商，不会发往任何地方。

  • NEW新增

    Export a whole video through your own engine. The SRT download can go through your provider instead of YouTube™'s free translation. It says how many requests it will take before it starts, shows progress, and can be stopped — and it is off by default, because it spends your quota and sends the whole track.

    导出整片字幕也能走自带引擎。下载 SRT 时可以用你自己的服务商翻译，而不是 YouTube™ 的免费整轨翻译。开始前会先告诉你大约几次请求，中途有进度、可以停；默认关闭，因为它会消耗你的额度、而且整片字幕会离开浏览器。

  • NEW新增

    Fifty translation languages, and you choose which ones show. The popup menu lists the ones you keep; the rest are one click away in Settings → Translation languages.

    译文语言增加到 50 种，显示哪些由你决定。弹窗下拉只列你留下的，其余的在「设置 → 译文语言列表」里随时加回来。

  • NEW新增

    A settings page, reachable from the gear. Getting started, translation service setup and About now live there. Seven more fonts, including a Chinese serif and a rounded face.

    齿轮里有了独立设置页。新手入门、翻译服务配置和「关于」都在里面。字体新增 7 种，含中文宋体与圆体。

  • IMPROVED改进

    Everything reads bigger. The settings text that used to be 10.5px is now 13px.

    整体字号调大。设置页原来 10.5px 的正文现在是 13px。

  • FIXED修复

    Subtitles dragged to the very bottom are no longer clipped, and a tab restored after a browser restart shows subtitles again without touching the CC button.

    字幕拖到最底部不再被裁掉半行；关掉浏览器再打开、恢复出来的标签页也不用手动开关 CC 就能出字幕。

  • FIXED修复

    Shorts turn their captions on by themselves now, and much sooner. A short has no CC button to press, so if your captions were switched off, nothing happened at all; now the track is asked for as soon as the player can answer — including the ones that used to stay blank until you swiped past them and came back.

    Shorts 现在会自己把字幕打开，而且快得多。短视频里没有 CC 按钮可点，所以此前只要你的字幕开关是关的，就一直是空白；现在播放器一能应答就去要字幕轨——快速连划时那些「划过去再划回来才出字幕」的短视频也一并修好了。

  • FIXED修复

    The automatic engine falls back to per-sentence translation far less often. One failed request used to keep a whole video on the fallback until you changed the engine by hand; it now tries again on its own. Speaker markers from auto-generated captions (>>) no longer show up in either line.

    「自动」引擎不再动不动就整场退回逐句翻译。此前只要有一次请求失败，整支视频就会一直停在退路上，除非你手动切引擎；现在它会自己再试。自动字幕里的换人说话标记（>>）也不会再出现在字幕里了。

  • FIXED修复

    Updating the extension no longer leaves a dead subtitle box behind in tabs that were already open — the old box now steps aside, and reloading the tab brings the new one.

    更新扩展后，已经开着的标签页不会再留下一个不再翻译的字幕框——旧的会自己退场，刷新一下就是新的。
